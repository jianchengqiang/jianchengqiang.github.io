家庭财富管家 · 使用说明书

记录收支 · 管理资产 · 规划存款　——　一本手机本地运行的家庭记账本

网址：https://jianchengqiang.github.io/　|　无需下载安装，装到桌面即可像 App 一样使用

1装到手机桌面（一次操作，永久可用）

本工具是一个网页应用，用 Safari / Chrome 打开网址后可“添加到主屏幕”，之后点桌面图标全屏进入，断网也能用。

iPhone（必须用 Safari，微信里打不开）

  1. 用 Safari 打开 https://jianchengqiang.github.io/
  2. 点底部中间的分享按钮（方框加向上箭头）
  3. 向下滑，选「添加到主屏幕」 → 右上角「添加」
  4. 桌面出现「财富管家」图标，点开即全屏进入，无地址栏

安卓手机

  1. 用 Chrome 打开同一网址
  2. 点右上角「⋮」→ 添加到主屏幕 / 安装应用
如果网址打不开：换备用地址（国内加速）：
https://cdn.jsdelivr.net/gh/jianchengqiang/jianchengqiang.github.io@main/index.html
注意：两个地址的数据不互通，选定一个之后请固定使用。
更新版本后：把 App 从后台划掉重新打开一次，就是最新版；不用重装，数据不会丢。

底部导航栏共 6 个页签，中间的圆形「＋」是记账入口：

总览明细理财＋ 记一笔目标分析设置
页签作用

3记一笔（核心操作）

点底部中间的 ＋ 弹出记账面板，选「收入」或「支出」→ 选分类 → 填金额 → 保存。

记收入

  • 选 工资 分类时，面板会变成「底薪 + 绩效」两栏，合计自动算出，明细里分别列出
  • 其他收入（兼职、红包等）直接填金额即可
  • 收入金额会自动进入「未划现金」（理财页可见），之后可手动划到支付宝/银行/零钱通

记支出

  • 选分类（餐饮、交通、购物、居家、医疗、教育、娱乐、人情、理财等）→ 部分分类会再选一个子项
  • 需要选择资金来源账户（支付宝 / 银行 / 零钱通 / 未划现金），保存后从该账户扣减
  • 若该账户余额不足：会扣到 0，并提示“有 ¥X 未扣到现金”，但账依然会记上

「理财」分类的特殊规则

记一笔支出 → 理财 → 选投入项（基金/黄金/股票等），等同于买入：现金减少、投资本金增加，总存款不变。现金合计不够时会拦截并提示，不会记成一本糊涂账。

其它字段

  • 日期：默认今天，可改（补记之前的花费记得改日期）
  • 备注：选填，建议写清楚用途，方便日后回看

4理财页：管钱的两个口袋

现金存款支付宝 / 银行 / 零钱通 / 未划现金（收入进来先落到“未划现金”）
投资存款本金 + 盈亏 = 投资金额，自动算收益率

未划现金 → 划入账户

  1. 理财页现金区，找到「未划现金」那一行
  2. 点右侧「划入账户」，选支付宝 / 银行 / 零钱通
  3. 填金额 → 确认，钱就从“未划”转到对应账户（总存款不变）

投资项目

  • 在投资区可添加/编辑项目（如基金、黄金、股票）
  • 每个项目填本金和当前盈亏，系统自动汇总「总投资金额 / 总盈亏 / 收益率」
  • 底部恒等式：总存款 = 现金存款 + 投资金额，可随时用来对账

5目标页：攒钱进度

  1. 点「＋ 新建目标」，填名称（如“换车基金”）和目标金额
  2. 日后攒到钱，点目标卡片 →「存入」→ 填金额，即可累加
  3. 卡片显示已存金额、进度条与剩余金额（若为负数会标红）

总览页的「存款目标进度」会同步显示，并可设置月度/年度目标存款，进度按 本月现金存款 + 本月投资存款 合计计算（设置页可调）。

6明细与分析

明细

  • 顶部可切换月份、按「全部 / 收入 / 支出」筛选
  • 每笔记录可删除（删除后现金、投资、目标相关数字会自动重算）

分析

  • 可切换年份，查看年收入 / 年支出 / 月均存款 / 储蓄率
  • 月度分析与建议：根据当月收支自动给出文字建议
  • 支出分类占比：饼图 + 图例，可切换月份
  • 月度存款趋势、收入 vs 支出柱状图，看全年走势

7设置项说明

设置项说明
默认年化收益率用于「存款增值规划」测算，按自己的预期填写
货币符号默认 ¥
月度目标存款进度 = 本月现金存款 + 本月投资存款

8数据备份与恢复（重要）

所有数据只存在你手机本机浏览器里，不上传服务器。换手机、清缓存、卸载查看器都会导致数据丢失——导出备份是唯一的保险。

导出备份

  1. 设置 →「导出备份」→ 得到一个 JSON 文件（如 财富管家备份_2026-10-29.json）
  2. 把它存到微信收藏 / 网盘 / 发给自己邮箱，建议每月一次

导入恢复

  1. 设置 →「导入备份」→ 选择之前保存的 JSON 文件
  2. 确认覆盖 → 数据完整恢复
导入会覆盖当前全部数据，操作前如有新账请先导出一份。

清空数据

设置 →「清空收支与目标」（标记为危险操作），只清收支记录与目标，保留设置。谨慎使用。

9几个人一起用会怎样？

  • 数据完全独立：每个人各自手机上是一本独立的账，互不相见、互不干扰
  • 只有程序是共用的：功能更新后，所有人打开都会拿到新版
  • 同一个人用两部手机登录，也是两套独立数据，不会自动同步
  • 建议每人只从桌面图标进入使用，不要同时在 Safari 里也记一遍，避免两边对不上账

如果需要一家人共用一本账（记完大家都能看到），需要把数据放到云端，可以另外提需求定制。

10常见问题

打开显示旧界面把 App 从后台划掉重开；网页缓存最多 10 分钟
底部出现红色警告条当前环境无法保存数据，请勿在此记账，改用主网址从 Safari 打开
金额对不上用「总存款 = 现金存款 + 投资金额」这条恒等式核对；投资口径是本金 + 盈亏
现金出现负数说明账户余额被扣多了，去理财页检查该账户，或补记一笔收入
换了新手机新手机装好 App → 设置 → 导入之前导出的 JSON 备份
网址打不开改用第二章的备用 CDN 地址；或检查网络
记账后没变化确认日期是否选对了月份，总览页左上角可切换查看月份

11日常使用建议

  • 随手记：花完立刻点「＋」记一笔，比事后补记准确得多
  • 每月对账：月底看一次「分析」页的支出占比，找出花钱大头
  • 每月备份：设置 → 导出备份，存到微信收藏，1 分钟的事
  • 定期划账：把「未划现金」划到实际账户，现金结构才清楚
本工具为记账与规划辅助工具，所有测算仅供参考，不构成投资建议。
